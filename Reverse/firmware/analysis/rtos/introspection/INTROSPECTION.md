# RTOS Introspection (1.0.12.83)

Static analysis of thread-dump and CPU/stack usage facilities in **M55**
(`platform_tester.bin`, FreeRTOS + embedded RTX5 dump code) and **BTH**
(`best1600_watch_bth.bin`, RTX5).

Sources recovered from `.rodata`:

| Path | Role |
|---|---|

| `../../rtos/rtx5/rtx_thread_dump.c` | `rtx_show_all_threads_usage` — full RTX walk |

## Getting a full runtime thread list on device

### Prerequisites

1. **Factory / MMI mode** — power on while holding the physical key **3 s**, then **5 s** if needed. BTH logs `!!!!!ENGINEER_MODE!!!!!`; M55 shows *MMI mode has been opened.*
2. **Wire-level shell** — Type-C is charge-only. Reach **`eshell >`** over:
   - **UART** test pads (primary; `hal_uart_open` via `eshell_platform.c`)
   - **`debug_i2c`** — rebinds the same shell over I2C (`debug_i2c` eshell command exists in image)

Prompt string: `eshell >` (M55 file offset `0x4274E2`, VA `0x2C4274E2` with XIP base).

### Commands (from `ps.c` name blob)

| Command | Help text (firmware) | Effect |
|---|---|---|
| `dump_all_threads` | *dump threads stack* | One-shot **full** RTX dump: every TCB field below, optional saved register frame, RTX memory pools, software timers |
| `show_threads_usage_once` | *show all threads usage* | One-shot **summary** line per thread (`name`, CPU %, min-free-stack) |
| `show_threads_usage` | — | Periodic usage (starts `cpu_usage_timer`) |
| `show_threads_uasges` | *show all threads usage* | Same intent; **typo preserved in binary** |
| `close_threads_usage` | *close threads usage* | Stop periodic usage timer |
| `close_threads_uasges` | — | Stop typo-variant timer |
| `ps` | *show status of threads* | Parent / help surface for thread status |

All of the above are present in **both** M55 and BTH images (1.0.12.83).

### Example session

```
eshell > dump_all_threads
Thread List:
--- Thread  0 thread=0x........ name=main
    prio=.. state=RUNNING   thread_addr=0x........
    thread_next=0x........ thread_prev=0x........ delay_next=0x........ delay_prev=0x........
    thread_join=0x........ flags_options=.. wait_flags=.. thread_flags=..
    stack_mem=0x........ stack_size=.... sp:0x.... min_stack_free=....
    ...
--- Memory common Stats:
...
--- Timers Stats:
...
```

For continuous monitoring without full TCB spam:

```
eshell > show_threads_usage_once
--- Thread name=eshell cpu=%2 min-free-stack=512
...
```

Handlers are **not** bound to Thumb VAs in this BES build (PIC + trace-hash). The mapping above is from the **contiguous `ps.c` eshell name blob** and co-located `rtx_show_all_threads_usage` string in `rtx_thread_dump.c`.

## RTX5 TCB layout (inferred from printf formats)

Both images ship identical format strings (M55 embeds the dump table **twice** — file offsets `0x149400` and `0x426900`, likely linked for different RTOS views / cores).

### State enumeration (`state=%-9s`)

Nine-character labels from rodata:

`BAD`, `INACTIVE`, `RUNNING`, `TERMINAT`, `WAIT_DLY`, `WAIT_JOIN`, `WAIT_FLAG`, `WAIT_SEM`, `WAIT_MEM`, `WAIT_MUT`, `READY`, `WAIT_EVE`, `WAIT_MGET`, `WAIT_MPUT`, `NULL`

Usage-summary path in `ps.c` also references: `Error`, `Inactive`, `Running`, `Blocked`, `Terminated`.

### Field diagram

```
                    RTX5 osRtxThread_t (inferred)
+------------------------------------------------------------------+
| identity                                                          |
|   thread          TCB pointer (printed as thread=0x%x)           |
|   name            char*                                           |
|   prio            osPriority_t                                    |
|   state           osRtxThreadState_t -> RUNNING / WAIT_DLY / ...  |
|   thread_addr     entry function PC                               |
+------------------------------------------------------------------+
| scheduler lists                                                   |
|   thread_next     ready-list next                                 |
|   thread_prev     ready-list prev                                 |
|   delay_next      delay-list next                                 |
|   delay_prev      delay-list prev                                 |
|   thread_join     join object / queue                             |
+------------------------------------------------------------------+
| flags                                                             |
|   flags_options   RTX thread flags + options word                 |
|   wait_flags      flags thread is waiting on                      |
|   thread_flags    thread-local flags                              |
+------------------------------------------------------------------+
| stack                                                             |
|   stack_mem       stack base                                      |
|   stack_size      bytes allocated                                 |
|   sp              current stack pointer (16-bit in dump: 0x%04x)  |
|   min_stack_free  high-water mark (bytes remaining)               |
+------------------------------------------------------------------+
| timing (usage / CPU accounting)                                   |
|   swap_in_time    ticks + ms                                      |
|   swap_out_time   ticks + ms                                      |
|   runtime         ticks + ms (running thread: "still runing")     |
+------------------------------------------------------------------+
| saved context (when frame present)                                |
|   frame           exception frame pointer                         |
|   R0,R1,R2,R3,R12,LR,PC,XPSR                                      |
+------------------------------------------------------------------+
```

### Printf format → field map

| Format fragment | Field |
|---|---|
| `--- Thread  %d thread=0x%x name=%s` | index, TCB, name |
| `prio=%u state=%-9s thread_addr=0x%08X` | prio, state, entry |
| `thread_next/prev`, `delay_next/prev` | list linkage |
| `thread_join`, `flags_options`, `wait_flags`, `thread_flags` | sync / flags |
| `stack_mem`, `stack_size`, `sp`, `min_stack_free` | stack |
| `swap_in/out_time=%u(ticks)/%u(ms)` | scheduler timestamps |
| `thread still runing, now %u(ticks)/%u(ms)` | live runtime |
| `frame:0x%08X` + register line | saved Cortex-M context |

Beyond threads, `rtx_show_all_threads_usage` also emits:

- `--- Memory common/stack/mp_data/mq_data Stats`
- `--- Timers Stats` with `Timer: %s`, callback pointer, state, type, tick/load

## FreeRTOS-specific introspection (M55 only)

M55 runs **FreeRTOS V10.4.1** on at least the HiFi4 DSP path (`hifi4 freertos run!`, `../../test/test_freertos.c`, `../../rtos/freertos/Source/tasks.c`).

| String | Offset (file) | Notes |
|---|---|---|
| `FreeRTOS V10.4.1` | — | Version marker |
| `vApplicationStackOverflowHook` | `0x12BA86` | Stack overflow hook compiled in |
| `pxTCB == pxCurrentTCB` | `0x12CED0` | Assert paths in `tasks.c` |
| `osGetThreadIntId` | `0x12BEDD` | CMSIS-RTOS2 shim over FreeRTOS |
| `smf_thread_print` / `%s:stack=%d/%d` | `0xC5F55` | SMF multimedia framework thread stack print |
| `[%d] stack [sp/share size : %p/%d]` | `0x1296CA` | Generic stack share dump |
| `--- Thread name=%s cpu=%%%d min-free-stack=%d` | `0x1494F0`, `0x42696C` | **Summary** line (CPU %, min stack) — used by usage commands, not full `vTaskList` |

**Not found in either binary:** `vTaskList`, `vTaskGetRunTimeStats`, `uxTaskGetStackHighWaterMark` as human-readable format strings. FreeRTOS introspection on M55 is therefore:

1. **RTX5 dump code** (shared BES `rtx_thread_dump.c`) for full thread walks on the RTX-managed side.
2. **Lightweight summary** format (`name`, `cpu%`, `min-free-stack`) for periodic usage.
3. **SMF / HiFi4** stack ratio prints (`used/total`) without a standard FreeRTOS task table API exposed at the shell.

BTH has **no FreeRTOS** strings; introspection is RTX5-only.

## Limitations

| Limitation | Detail |
|---|---|
| Handler VAs unrecovered | BES PIC + trace-hash: no xrefs from command names to Thumb entry points. Use on-device trace or Ghidra recursive descent of `ps.c`. |
| Dual dump tables on M55 | Two identical `rtx_thread_dump.c` string clusters — dump may target different RTOS instances (application RTX vs coprocessor view). Interpret `thread=` addresses against the correct memory map. |
| Typo commands | `show_threads_uasges` / `close_threads_uasges` are real registered names; do not assume corrected spelling works. |
| No `vTaskList` | Cannot expect classic FreeRTOS table output; use `dump_all_threads` for RTX TCB detail or `show_threads_usage_once` for summary. |
| Transport required | Commands exist in firmware but are unreachable without UART / `debug_i2c` hardware access. |
| Register frame optional | Full `R0`–`XPSR` block only printed when a saved frame exists (blocked/interrupted threads). |
| Timer section side effect | `dump_all_threads` walks all RTX timers — verbose and may perturb timing if called under load. |
